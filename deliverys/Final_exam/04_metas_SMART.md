## 1. Objetivos de investigación vs. metas estratégicas

Esta distinción va explícita en el deck:

| | Objetivos de investigación (SO1–SO5, lámina 9) | Metas estratégicas (nuevo) |
| --- | --- | --- |
| Responden a | ¿Qué necesitamos **entender**? | ¿Qué tenemos que **lograr** para que cada línea funcione? |
| Nacen de | El problema de decisión (asimetría de información) | El FODA: cada línea cruza un ítem interno con uno externo |
| Se cumplen con | El estudio de 4 semanas (60 dealers + 180 compradores) | Un piloto, acuerdos o el siguiente estudio |
| Relación | Un SO **valida** una meta: dice si el umbral es razonable antes de comprometerlo | Una meta solo se compromete después de que su SO la valida |

**Horizonte:** el mes 1 es el estudio (SO1–SO5, semanas 1–4, lámina 9). Los meses 2–3 son el piloto y el siguiente estudio (talleres y aseguradoras). El mes 6 es la decisión de lanzamiento.

## 3. Metas SMART (formato S/M/A/R/T de la lámina 9)

Los umbrales son **metas propuestas por el equipo**, no datos de mercado. Cada umbral lleva su argumento y se ajusta con el resultado del SO que lo valida.

### Meta 1 · Proof, not promises

| | |
| --- | --- |
| **S** | Un piloto de reportes revisados por mecánico, donde cada reporte muestra lo que vio, un rango de costo con su confianza y lo que no puede ver. |
| **M** | En 100 reportes revisados por mecánico (el mismo tamaño que el estudio de referencia), **≤ 10 % con contenido inventado** y **100 % con la sección “what it cannot see”**. |
| **A** | La línea base publicada, con el modelo anclado a uno de segmentación de daños, es de **31 %** de reportes con contenido inventado, frente a 78 % con un modelo general solo (Hogale et al., 2026). Bajar a ≤ 10 % exige sumar la revisión humana que ya plantea S2. |
| **R** | La exactitud es la barrera más citada por los dealers (74 %; Cox Automotive, 2025), y la empresa responde por lo que dice su IA (American Bar Association, 2024). Una prueba con cifras es lo que no entrega un chatbot gratuito (T1). |
| **T** | Mes 3, al cierre del piloto. |
| **Origen** | S2 · W1 · O2 → T1 · T3 · T4 |
| **Valida** | **SO1** (qué clases de daño debe detectar y reportar el piloto) y **SO3** (qué explicación del reporte baja la desconfianza). |

### Meta 2 · Local data as the barrier

| | |
| --- | --- |
| **S** | Una base chilena inicial de costos de reparación de carrocería y de precios reales de compra. |
| **M** | (a) Precios reales de compra de los **60 dealers** de SO2, para calibrar el modelo de precio (W2). (b) **6–8 talleres entrevistados**, de los cuales **≥ 3** comparten sus precios de mano de obra y repuestos. |
| **A** | La parte (a) ocurre dentro del estudio. La parte (b) es pequeña a propósito: los talleres llenos tienen poco incentivo (29 días hasta entrar al taller; CMF, 2026b). |
| **R** | La tecnología base es barata y accesible (T-14, T-11), así que la barrera está en los datos locales (Fuerza 2). Además, las marcas chinas no tienen una curva pública de reventa (O5). |
| **T** | (a) Semana 4. (b) Mes 3, en el siguiente estudio. |
| **Origen** | W2 · W3 · O3 · O5 → T2 |
| **Valida** | **SO2** para la parte (a). **Siguiente estudio con talleres** para la parte (b): los talleres no están en la muestra actual (#4). |

### Meta 3 · Insurers, a third market

| | |
| --- | --- |
| **S** | Saber si las aseguradoras comprarían una pre-inspección de daños para emitir pólizas. |
| **M** | **3–4 entrevistas** a aseguradoras y **1 acuerdo de piloto** para el paquete de pre-inspección (incluye la foto del bajo del auto, una idea de clase). |
| **A** | Hay pocos compradores y son grandes (2,23M de autos asegurados; CMF, 2026b), así que unas pocas entrevistas cubren buena parte del mercado. |
| **R** | Las aseguradoras ya aceptan fotos (Mapfre Chile Seguros, s. f.), pero también pueden construir su propia solución (T2). Conviene saberlo antes de invertir en esta línea. |
| **T** | Mes 6, siguiente estudio. |
| **Origen** | S1 · O4 → T2 |
| **Valida** | **Siguiente estudio con aseguradoras.** Ningún SO actual la valida (#4). |

### Meta 4 · Subscription, easy start

| | |
| --- | --- |
| **S** | Dealers pagando el plan mensual, con un precio dentro del rango aceptable para su tamaño. |
| **M** | **10 dealers** suscritos al plan mensual (≈2 % de los 487 de Santiago; 1 de cada 6 entrevistados en SO5), con el precio dentro del rango Van Westendorp de su tramo SII. |
| **A** | Se instala en una visita y no requiere hardware (S1). La meta es baja a propósito: la marca es nueva (W4) y para el comprador irse no cuesta nada (T5). |
| **R** | Con 59.900 al mes, el plan cuesta ≈CLP 20.000 por auto para el dealer promedio (≈3 autos al mes). Para el que compra ≈1, cuesta lo mismo que una inspección (S3). SO5 dice en qué tramo sí conviene. |
| **T** | Mes 3. |
| **Origen** | S3 · S4 · W4 · O1 → T5 · T3 |
| **Valida** | **SO5** (Top-2 Box + Van Westendorp por tramo SII). La forma de pago preferida se levanta como pregunta abierta en el mismo instrumento. |
